# Deployment Guide — Beatly

Backend → **Render**, Frontend → **Vercel**, Database → **MongoDB Atlas**.

## 1. Backend on Render

1. Push the repo to GitHub.
2. Render → **New → Blueprint** → pick the repo. It reads [`render.yaml`](render.yaml)
   (root dir `backend`, health check `/api/health`, `JWT_SECRET` auto-generated).
   *Or* create a Web Service manually: root dir `backend`, build `npm ci --omit=dev`, start `npm start`.
3. Set these environment variables:

   | Key | Value |
   |-----|-------|
   | `MONGO_URI` | Atlas connection string |
   | `IMAGEKIT_PRIVATE_KEY` | ImageKit private key |
   | `IMAGEKIT_PUBLIC_KEY` | ImageKit public key |
   | `IMAGEKIT_URL_ENDPOINT` | e.g. `https://ik.imagekit.io/<your_id>` |
   | `FRONTEND_URL` | `https://<your-app>.vercel.app` (comma-separate multiple origins, no trailing slash) |
   | `JWT_SECRET` | long random string (auto-generated by the blueprint) |
   | `NODE_ENV` | `production` |
   | `ARTIST_EMAIL` | login email for the artist panel |
   | `ARTIST_PASSWORD` | login password for the artist panel |
   | `ARTIST_NAME` | display name (default `Beatly Artist`) |

   Don't set `PORT`. Render provides it.
4. In MongoDB Atlas → Network Access, allow `0.0.0.0/0` (Render has no fixed IPs on free plans).
5. Check `https://<service>.onrender.com/api/health` returns `{"status":"ok"}`.

## 2. Frontend on Vercel

1. Vercel → **Add New Project** → import the repo → **Root Directory: `frontend`**.
2. Environment variable: `VITE_API_URL=https://<service>.onrender.com/api`
3. Deploy. [`frontend/vercel.json`](frontend/vercel.json) rewrites all routes to `index.html` so page refreshes work.
4. Copy the Vercel URL back into Render's `FRONTEND_URL` and redeploy the backend.

## 3. Local development

```bash
cd backend                            # put your values in backend/.env
npm install && npm run dev            # http://localhost:5000

cd frontend                           # VITE_API_URL in frontend/.env
npm install && npm run dev            # http://localhost:3000
```

## Notes

- Sign-up always creates a **listener** account. There is no artist option.
- The only **artist** (upload panel) account is the one set by `ARTIST_EMAIL` / `ARTIST_PASSWORD`.
  It's created or updated each time the backend starts, so change the password by changing the env var and redeploying.
  Log in with it on the normal Sign In page.
- The backend refuses to start if `MONGO_URI`, `JWT_SECRET`, `IMAGEKIT_PRIVATE_KEY` or `IMAGEKIT_PUBLIC_KEY` is missing.
- Songs upload straight from the browser to ImageKit. The backend only signs the upload and saves the song details.
- Render free instances sleep when idle. The first request after a pause can take ~30–50s.
